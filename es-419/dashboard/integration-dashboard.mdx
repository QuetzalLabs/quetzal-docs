El Dashboard de Integración de Quetzal es una ventana para configurar y monitorear tus integraciones.

Se puede acceder seleccionando ["Integraciones"](https://getquetzal.com/dashboard/integrations) en el menú de navegación del dashboard principal.

## Administrando tu integración

El dashboard de integración ofrece herramientas para configurar ajustes y monitorear el trabajo de Quetzal.

A medida que tu código es procesado, las cadenas, traducciones y texto del código serán visibles. Los cambios realizados al contenido en el dashboard se propagarán al control de versiones según la configuración.

Las funcionalidades de Quetzal se pueden activar o desactivar en la pestaña Configuración de Contenido, y las reglas sobre cómo Quetzal interactúa con tu control de versiones se pueden configurar en la pestaña Cambios.

## Pestaña Cambios

Este panel muestra las ramas que Quetzal está monitoreando y actualizando actualmente.

Cada rama listada aquí será monitoreada en tiempo real para detectar cambios que afecten la localización.

Las acciones disponibles:
- Eliminar: Elimina la rama del monitoreo. Las actualizaciones se detendrán.
- Restablecer: Revierte cualquier procesamiento y lo ejecuta desde cero. Esto puede ser necesario si los ajustes fueron modificados extensamente y el procesamiento realizado quedó desactualizado.

El panel de ajustes te permite definir el comportamiento de estas ramas.
Se pueden configurar reglas para procesar automáticamente nuevas ramas.
Los cambios se pueden configurar para publicarse mediante pull request, commits directos, o no publicarse en absoluto.
La opción "Fusionar traducciones automáticamente en la rama principal de forma independiente" se puede activar para fusionar automáticamente las nuevas traducciones en main a medida que estén listas.

Para más detalle sobre los cambios que Quetzal publicará, consulta nuestra documentación sobre cómo se aplican los cambios.

<Tip>
  Se pueden agregar nuevas ramas de tres formas: Automatización, el botón 'Agregar rama', o comentando /quetzal start en un pull request. [Más información](/es-419/install/committing-changes)
</Tip>

## Pestaña Traducciones

La pestaña de traducciones tiene la misma estructura que tu pestaña principal de traducciones, pero limitada a la integración actual.

Los tres paneles dan acceso de lectura y actualización a:
- Cadenas en tu app y sus traducciones
- Términos del glosario en tu app y sus traducciones
- Revisiones de traducciones propuestas para confirmar o rechazar.

## Configuración de Contenido

Esta pestaña define los ajustes centrales del comportamiento de tu integración de Quetzal.

El conjunto principal de funcionalidades se puede activar y desactivar en la primera pestaña General:
- Realizar traducciones: Quetzal generará las traducciones faltantes. Si está desactivado, las cadenas sin traducir se quedarán así.
- Auditar traducciones existentes: Quetzal propondrá revisiones a las traducciones existentes. Si está desactivado, las traducciones existentes nunca se modificarán.
- Wrappear cadenas faltantes: Quetzal modificará tu código para asegurar que todo el contenido visible al usuario esté traducido. Si está desactivado, tu código nunca será modificado.
- Traducir contenido especial: Intenta traducir imágenes y otro contenido avanzado (Beta)
- Archivos de texto: Actualiza archivos de texto localizados cada vez que su fuente se actualice (Beta)

### Configuración de Wrapping

Si "Wrappear cadenas faltantes" está activado, ajustes adicionales determinarán cómo y cuándo Quetzal actualizará tu código para traducir las cadenas faltantes.

Se pueden listar tipos de archivo para limitar las actualizaciones a tipos de archivo específicos.

Reglas de contenido: Directrices proporcionadas a la IA para limitar qué cadenas se clasifican como pendientes de traducción.

Refactorización: Por defecto, refactorizaremos tu código de forma mínima para asegurar que la localización funcione. Esto nunca implicará reescrituras grandes, sino ediciones pequeñas como mover cadenas o agregar mecanismos dentro del alcance. Puedes desactivar esto o indicar directrices particulares.

## Idioma

Define en qué locales traducir para esta integración.

También hay tres secciones para agregar directrices que la IA considerará:
- Para traducir a cada locale
- Para traducir términos del glosario
- Para auditar traducciones existentes

## Claves

Define directrices para la definición de claves de traducción dentro de tu código.

## Avanzado / LOCALIZATION.md

La pestaña Avanzado te permite modificar el archivo LOCALIZATION.md que define los patrones de localización que sigue tu código.

Se genera automáticamente al vincular, pero se puede actualizar si algún patrón es incorrecto o incompleto.

Se consulta este documento cada vez que la IA actualiza el código. Si "Wrappear cadenas faltantes" está desactivado, este documento es mayormente irrelevante.
