## Integrar con Quetzal

Una vez que tu código esté vinculado con Quetzal, podemos comenzar a entregar actualizaciones de localización a través del control de versiones.

## Requisitos previos

Quetzal actualmente solo soporta repositorios alojados en GitHub. Verifica que tu stack sea compatible leyendo nuestros stacks soportados.

## Vincular un repositorio

Una vez que te hayas [registrado](https://getquetzal.com/signup), puedes [vincular un repositorio](https://getquetzal.com/onboarding)

Se te pedirá instalar la app de GitHub de Quetzal para conceder acceso a uno o más repositorios.

Una vez instalada, se te pedirá seleccionar uno para completar la instalación.

## Seleccionar directorio

Se te pedirá limitar la integración de Quetzal a directorios específicos.

Si tienes un repo con múltiples patrones de localización distintos (es decir, un monorepo) es mejor configurar múltiples integraciones en el mismo repo con directorios que no se superpongan.

Si tu repositorio solo tiene los mismos patrones de localización en todo el proyecto, puedes dejar esto en blanco.

## Definir locales

Se te pedirá definir qué locales te gustaría soportar para esta integración.

Si los locales ya están definidos en tu código, puedes marcar "Usa los idiomas que ya están en uso en tu código"

De lo contrario, esta es tu oportunidad de definir el conjunto de idiomas.

Esto se puede actualizar después.

## Próximos pasos

Se te indicará que la vinculación está completa y serás llevado al [dashboard de integración](https://getquetzal.com/dashboard/integration)

Quetzal tomará un tiempo para revisar tu código y planificar los próximos pasos.

Aquí puedes monitorear el progreso y configurar el comportamiento de tu integración. Para una guía completa sobre cómo usar este dashboard, lee nuestra especificación del Dashboard de Integración.
