## Integrar con Quetzal

Una vez que tu codebase esté vinculado con Quetzal, podemos empezar a entregar actualizaciones de localización mediante control de versiones.

## Requisitos previos

Quetzal actualmente solo admite repositorios alojados en GitHub. Verifica que tu stack sea compatible consultando nuestros stacks compatibles.

## Vincular un repositorio

Una vez que te hayas [registrado](https://getquetzal.com/signup), puedes [vincular un repositorio](https://getquetzal.com/onboarding)

Se te pedirá instalar la app de GitHub de Quetzal para otorgar acceso a uno o más repositorios.

Una vez instalada, se te pedirá seleccionar uno para completar la instalación.

## Seleccionar directorio

Se te pedirá delimitar la integración de Quetzal a directorios específicos.

Si tienes un repositorio con múltiples patrones de localización distintos (p.ej., un monorepo), lo mejor es configurar múltiples integraciones en el mismo repositorio con directorios que no se superpongan.

Si tu repositorio tiene los mismos patrones de localización en todo su contenido, puedes dejar esto en blanco.

## Definir locales

Se te pedirá definir qué locales deseas admitir para esta integración.

Si los locales ya están definidos en el codebase, puedes marcar "Usar los locales actualmente en uso en el codebase"

De lo contrario, esta es tu oportunidad para definir el conjunto de idiomas.

Esto puede actualizarse más adelante.

## Próximos pasos

Se te notificará que la vinculación está completa y serás llevado al [dashboard de integración](https://getquetzal.com/dashboard/integration)

Quetzal tomará un tiempo para revisar tu código y planificar los próximos pasos.

Aquí puedes monitorear el progreso y configurar el comportamiento de tu integración. Para una guía completa sobre el uso de este dashboard, lee nuestra spec del Dashboard de Integración.
