## Lista de verificación

Quetzal está diseñado para funcionar con todos los stacks y todos los patrones de localización.

Sin embargo, aún hay algunos requisitos.

## Contenido traducible

Quetzal está pensado para traducir cadenas estáticas definidas en tu código. Para cualquier otra cosa, puedes usar nuestra API.

Esto incluye cadenas de UI, documentos de texto puro y otras cadenas definidas en archivos de código.

Imágenes, cadenas generadas por el usuario u otras cadenas encontradas en tiempo de ejecución no están dentro del alcance de estas herramientas.

## Formatos soportados

Actualmente, Quetzal funciona con los siguientes stacks:

- Javascript/Typescript
- Next.js/React
- Swift
- Kotlin
- Java
- Python
- HTML/XML
- Documentos de texto (.txt, .mdx, etc.)

En este momento, NO soportamos:

- Vue/Svelte

Quetzal está diseñado para manejar todos los stacks de forma elegante. Por eso, si tu framework no está en la lista pero te interesa, no dudes en contactarnos. Estamos emocionados de darle vida a Quetzal para tu stack.

## Librerías de traducción soportadas

Quetzal debería funcionar con todas las librerías y patrones de traducción.
Sin embargo, Quetzal puede tener dificultades para navegar anti-patrones si tu framework de localización está mal configurado o mal definido.

Si estás usando un framework de traducción con capacidades limitadas, Quetzal puede tener dificultades para localizar correctamente dadas las restricciones.
Puntos ciegos comunes de patrones de localización débiles incluyen:
- Pluralización
- Contenido dinámico
- Mecanismo frágil de claves de cadenas
- Cadenas fragmentadas

La mayoría de los mecanismos de traducción reconocidos manejan esto perfectamente. Consulta nuestros consejos sobre [elegir un framework](/es-419/install/choosing-a-framework).

Durante la configuración inicial, puedes revisar y actualizar un archivo LOCALIZATION.md generado para alinear Quetzal con las prácticas que mejor funcionen para tu equipo.

## Archivos de texto crudo

Nuestro soporte para contenido traducido en texto crudo está actualmente en beta.

Si tienes documentación, publicaciones de blog u otros archivos escritos como texto o markdown donde existen múltiples versiones para cada locale, Quetzal puede tener dificultades para conectarse con los mecanismos requeridos. Monitorea de cerca una integración así para asegurar que el comportamiento inicial sea correcto.
