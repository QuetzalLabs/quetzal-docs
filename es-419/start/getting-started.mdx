## ¡Bienvenido a Quetzal!

Esta documentación te guiará en cómo configurar y usar Quetzal con tu stack.

## Localización de Codebase

Quetzal está diseñado para mantener la localización de contenido estático en tu aplicación.
La integración funciona de manera un poco diferente dependiendo del estado actual de tu código:

<Card title="Sin Localización" icon="sprout" href="/en-US/start/first-time-localization">
  Ningún contenido de mi codebase está traducido y estoy buscando empezar
</Card>
<Card title="Algo de Localización" icon="form" href="/en-US/start/existing-localization">
  Existe un sistema de localización, pero se usa poco o nada.
</Card>
<Card title="Localización Extensiva" icon="form" href="/en-US/existing-localization">
  Ya existe un sistema de localización y se usa extensamente.
</Card>

## Localización de Contenido Generado

Para traducir contenido no estático (contenido generado por el usuario, contenido generado en tiempo de ejecución), nuestra API está disponible.

Habla con nosotros para asegurarte de que el perfil de uso sea compatible con Quetzal.

### Pasos de Integración

La integración generalmente consta de cuatro pasos:

<Steps>
  <Step title="Vincula Tu Repositorio">
    [Regístrate](https://getquetzal.com/signup) en Quetzal y se te pedirá que instales la Quetzal GitHub App. Si ya tienes una cuenta, puedes [vincular un repositorio directamente](https://getquetzal.com/onboarding)
  </Step>
  <Step title="Espera el Análisis">
    Nuestro análisis y sincronización iniciales determinarán la compatibilidad.
  </Step>
  <Step title="Actualiza la Configuración">
    Usa el [Dashboard de Integración](https://getquetzal.com/dashboard) para confirmar la configuración.
  </Step>
  <Step title="Fusiona los Cambios">
    A partir de ahora, las actualizaciones de localización se publicarán en git mediante pull requests o commits directos
  </Step>
</Steps>
