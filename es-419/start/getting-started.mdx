## ¡Bienvenido a Quetzal!

Esta documentación te guiará sobre cómo configurar y usar Quetzal con tu stack.

## Localización de código

Quetzal está diseñado para mantener la localización del contenido estático en tu aplicación.
La integración funciona un poco diferente dependiendo del estado actual de tu código:

<Card title="Sin localización" icon="sprout" href="/en-US/start/first-time-localization">
  Ningún contenido en mi código está traducido, y quiero empezar
</Card>
<Card title="Algo de localización" icon="form" href="/en-US/start/existing-localization">
  Hay un sistema de localización, pero no se usa mucho o en absoluto.
</Card>
<Card title="Localización extensa" icon="form" href="/en-US/existing-localization">
  Ya hay un sistema de localización y se usa extensamente.
</Card>

## Localización de contenido generado

Para traducir contenido no estático (contenido generado por el usuario, contenido generado en tiempo de ejecución), nuestra API está disponible.

Habla con nosotros para asegurarte de que el perfil de uso se adapte bien a Quetzal.

### Pasos de integración

Integrar generalmente toma cuatro pasos:

<Steps>
  <Step title="Vincula tu repositorio">
    [Regístrate](https://getquetzal.com/signup) en Quetzal y se te pedirá
    instalar la app de GitHub de Quetzal. Si ya tienes una cuenta, puedes [vincular un repositorio directamente](https://getquetzal.com/onboarding)
  </Step>
  <Step title="Espera el análisis">
    Nuestro análisis inicial y sincronización determinarán la compatibilidad.
  </Step>
  <Step title="Actualiza los ajustes">
    Usa el [Dashboard de Integración](https://getquetzal.com/dashboard) para confirmar los ajustes.
  </Step>
  <Step title="Fusiona los cambios">
    De aquí en adelante, las actualizaciones de localización se publicarán en git mediante pull requests o commits directos
  </Step>
</Steps>
