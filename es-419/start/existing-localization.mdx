## Integrar con Quetzal

Si tu código tiene un sistema de localización existente, Quetzal puede mantenerlo de aquí en adelante.

Quetzal seguirá tus prácticas existentes para actualizar y auditar la localización.

Puedes empezar [vinculando tu código](/es-419/install/linking-a-repository). Esto creará una integración para proporcionar actualizaciones de localización a tu código vía git.

## ¿Qué hará Quetzal?

Una vez vinculado, Quetzal traducirá el contenido futuro, verificará la calidad de las traducciones existentes y actualizará tu código para asegurar cobertura de traducción completa.

Esta integración actualmente solo soporta contenido estático. El contenido generado en tiempo de ejecución, traducido o no, no será afectado por esta integración. Para traducir contenido en tiempo de ejecución, puedes usar tu API.

Las funcionalidades se pueden activar y desactivar en los ajustes una vez que un repositorio esté vinculado.

## Compatibilidad

Para asegurarte de que tu stack funcione con Quetzal de antemano, puedes [verificar la compatibilidad con Quetzal](/es-419/install/is-my-stack-supported).
