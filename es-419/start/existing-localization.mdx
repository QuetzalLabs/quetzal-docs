## Integrando con Quetzal

Si tu codebase tiene un sistema de localización existente, Quetzal puede mantenerlo en adelante.

Quetzal se adherirá a tus prácticas existentes para actualizar y auditar la localización.

Puedes comenzar [vinculando tu codebase](/en-US/install/linking-a-repository). Esto creará una integración para proveer actualizaciones de localización a tu código vía git.

## ¿Qué hará Quetzal?

Una vez vinculado, Quetzal traducirá el contenido futuro, verificará la calidad de las traducciones existentes y actualizará tu código para garantizar cobertura total de traducción.

Esta integración actualmente solo admite contenido estático. El contenido generado en tiempo de ejecución, traducido o no, no se verá afectado por esta integración. Para traducir contenido en tiempo de ejecución, puedes usar tu API.

Las funciones pueden activarse o desactivarse en la configuración una vez que un repositorio esté vinculado.

## Compatibilidad

Para asegurarte de que tu stack funciona con Quetzal con anticipación, puedes [verificar la compatibilidad con Quetzal](/en-US/install/is-my-stack-supported).
