<Tip>
  Ojo: Para aplicaciones Swift, no necesitas tener localización existente para localizar con Quetzal. Swift tiene patrones de localización estandarizados que se seguirán.
</Tip>

## Configurando la localización

Quetzal se conecta con tus patrones de localización existentes, pero no los proporciona, instala ni configura por ti.

Antes de vincular tu código con Quetzal, deberías empezar configurando un sistema de localización y traduciendo algunas cadenas para probar.

Quetzal se encargará del resto. Una vez que las bases para la localización estén en tu código, puedes pasar a [vincular tu código](/es-419/install/linking-a-repository).

## Recursos

Para ayuda eligiendo un esquema de localización que se adapte bien a tu código, puedes leer [nuestros consejos](/es-419/install/choosing-a-framework).

Para asegurarte de que tu stack funcione con Quetzal de antemano, puedes [verificar la compatibilidad con Quetzal](/es-419/install/is-my-stack-supported).
