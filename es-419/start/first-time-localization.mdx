<Tip>
  Ojo: Para aplicaciones Swift, no se requiere localización existente para localizar con Quetzal. Swift tiene patrones de localización estandarizados a los que se adhiere.
</Tip>

## Configurando la Localización

Quetzal se integra con tus patrones de localización existentes, pero no los provee, instala ni configura para ti.

Antes de vincular tu codebase con Quetzal, deberías comenzar por configurar un sistema de localización y traducir algunas cadenas para probar.

Quetzal se encarga del resto. Una vez que la base de la localización esté en tu código, puedes pasar a [vincular tu codebase](/en-US/install/linking-a-repository).

## Recursos

Para elegir un esquema de localización que sea una buena opción para tu codebase, puedes leer [nuestros consejos](/en-US/install/choosing-a-framework).

Para asegurarte de que tu stack funciona con Quetzal con anticipación, puedes [verificar la compatibilidad con Quetzal](/en-US/install/is-my-stack-supported).
