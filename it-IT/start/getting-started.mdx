## Benvenuto su Quetzal!

Questa documentazione ti guiderà su come configurare e usare Quetzal con il tuo stack.

## Localizzazione del Codebase

Quetzal è progettato per mantenere la localizzazione del contenuto statico nella tua applicazione.
L'integrazione funziona in modo leggermente diverso a seconda dello stato attuale del tuo codice:

<Card title="Nessuna Localizzazione" icon="sprout" href="/en-US/start/first-time-localization">
  Nessun contenuto nel mio codebase è tradotto e sto cercando di iniziare
</Card>
<Card title="Localizzazione Parziale" icon="form" href="/en-US/start/existing-localization">
  C'è un sistema di localizzazione, ma non è usato molto o per niente.
</Card>
<Card title="Localizzazione Estesa" icon="form" href="/en-US/existing-localization">
  C'è già un sistema di localizzazione ed è usato ampiamente.
</Card>

## Localizzazione dei Contenuti Generati

Per tradurre contenuto non statico (contenuto generato dall'utente, contenuto generato a runtime), la nostra API è disponibile.

Parlane con noi per assicurarti che il profilo d'uso sia adatto a Quetzal.

### Passi dell'Integrazione

L'integrazione richiede generalmente quattro passi:

<Steps>
  <Step title="Connetti il Tuo Repository">
    [Registrati](https://getquetzal.com/signup) su Quetzal e ti verrà chiesto di installare l'app GitHub di Quetzal. Se hai già un account, puoi [connettere un repository direttamente](https://getquetzal.com/onboarding)
  </Step>
  <Step title="Attendi l'Analisi">
    La nostra analisi e sincronizzazione iniziali determineranno la compatibilità.
  </Step>
  <Step title="Aggiorna le Impostazioni">
    Usa la [Dashboard di Integrazione](https://getquetzal.com/dashboard) per confermare le impostazioni.
  </Step>
  <Step title="Unisci le Modifiche">
    D'ora in poi, gli aggiornamenti di localizzazione verranno pubblicati su git tramite pull request o commit diretti
  </Step>
</Steps>
