## Benvenuto in Quetzal!

Questa documentazione ti guiderà su come configurare e usare Quetzal con il tuo stack.

## Localizzazione del Codebase

Quetzal è progettato per mantenere la localizzazione dei contenuti statici nella tua applicazione.
L'integrazione funziona in modo leggermente diverso a seconda dello stato attuale del tuo codice:

<Card title="Nessuna Localizzazione" icon="sprout" href="/en-US/start/first-time-localization">
  Nessun contenuto nel mio codebase è tradotto, e voglio iniziare
</Card>
<Card title="Localizzazione Parziale" icon="form" href="/en-US/start/existing-localization">
  C'è un sistema di localizzazione, ma viene usato poco o per niente.
</Card>
<Card title="Localizzazione Estesa" icon="form" href="/en-US/existing-localization">
  C'è già un sistema di localizzazione ed è utilizzato in modo estensivo.
</Card>

## Localizzazione dei Contenuti Generati

Per tradurre i contenuti non statici (contenuti generati dagli utenti, contenuti generati a runtime), la nostra API è disponibile.

Parla con noi per assicurarti che il profilo d'uso sia adatto a Quetzal.

### Passi dell'Integrazione

L'integrazione richiede generalmente quattro passi:

<Steps>
  <Step title="Connetti il Tuo Repository">
    [Registrati](https://getquetzal.com/signup) su Quetzal e ti verrà chiesto di installare l'app GitHub di Quetzal. Se hai già un account, puoi [connettere direttamente un repository](https://getquetzal.com/onboarding)
  </Step>
  <Step title="Attendi l'Analisi">
    La nostra analisi iniziale e la sincronizzazione determineranno la compatibilità.
  </Step>
  <Step title="Aggiorna le Impostazioni">
    Usa la [Dashboard di Integrazione](https://getquetzal.com/dashboard) per confermare le impostazioni.
  </Step>
  <Step title="Unisci le Modifiche">
    D'ora in poi, gli aggiornamenti della localizzazione verranno pubblicati su git tramite pull request o commit diretti
  </Step>
</Steps>
