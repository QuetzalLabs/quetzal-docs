Quetzal pubblica le modifiche al tuo codebase tramite il controllo di versione.

La tempistica e la struttura delle modifiche possono essere configurate per adattarsi al meglio al flusso di lavoro del tuo team.

## Cosa Viene Pubblicato?

Nuove traduzioni, traduzioni

- Nuove traduzioni
- Revisioni di traduzione
- Aggiornamenti del codice per la copertura di localizzazione

Queste funzionalità possono essere attivate e disattivate nelle impostazioni della tua integrazione.

## Come Vengono Pubblicate le Modifiche

Le modifiche vengono applicate al tuo codebase tramite commit su GitHub.

Per impostazione predefinita, le modifiche vengono pubblicate su un singolo branch tramite un'unica pull request dedicata alla localizzazione.

Puoi cambiare questa impostazione per pubblicare invece tramite commit diretti

## Branch attivi

Per impostazione predefinita, Quetzal monitora un solo branch e vi pubblica le modifiche.

Puoi aggiungere nuovi branch da monitorare impostando un filtro per i nuovi branch da elaborare, oppure invocando Quetzal nei commenti di una pull request.

I branch possono anche essere aggiunti manualmente tramite la dashboard.

I branch attivi vengono elaborati e aggiornati da Quetzal in tempo reale, assicurando che la localizzazione sia sempre aggiornata.


## Branch Solo Traduzioni

Hai la possibilità di separare gli aggiornamenti delle traduzioni dagli altri aggiornamenti del codice.

Questo permetterebbe di unire automaticamente le modifiche delle traduzioni nel main, lasciando le altre modifiche del codice da pubblicare tramite un pattern diverso.

## Aggiornamenti Manuali

Se preferisci aggiornare il tuo codebase manualmente, puoi invece recuperare le modifiche tramite la nostra API. 

Le modifiche possono essere interrogate e integrate nel tuo flusso di lavoro in autonomia, per il massimo controllo.
