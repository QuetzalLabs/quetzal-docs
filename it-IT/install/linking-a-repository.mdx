## Integrazione con Quetzal

Una volta che il tuo codebase è connesso con Quetzal, possiamo iniziare a distribuire aggiornamenti di localizzazione tramite il controllo di versione.

## Prerequisiti

Quetzal attualmente supporta solo repository ospitati su GitHub. Verifica che il tuo stack sia supportato leggendo i nostri stack supportati.

## Connettere un Repository

Una volta che ti sei [registrato](https://getquetzal.com/signup), puoi [connettere un repository](https://getquetzal.com/onboarding)

Ti verrà chiesto di installare l'app GitHub di Quetzal per concedere l'accesso a uno o più repository.

Una volta installata, ti verrà chiesto di selezionarne uno per completare l'installazione.

## Selezione della Directory

Ti verrà chiesto di delimitare l'integrazione Quetzal a directory specifiche.

Se hai un repo con più pattern di localizzazione distinti (ad es. un monorepo) è meglio configurare più integrazioni nello stesso repo con directory che non si sovrappongono.

Se il tuo repository ha gli stessi pattern di localizzazione ovunque, puoi lasciare questo campo vuoto.

## Definizione delle Lingue

Ti verrà chiesto di definire quali lingue desideri supportare per questa integrazione.

Se le lingue sono già definite nel codebase, puoi spuntare "Usa i locale attualmente in uso nel codebase"

Altrimenti, questa è la tua occasione per definire l'insieme delle lingue.

Questo può essere aggiornato in seguito.

## Prossimi Passi

Ti verrà comunicato che la connessione è completata e verrai portato alla [dashboard di integrazione](https://getquetzal.com/dashboard/integration)

Quetzal impiegherà un po' di tempo per analizzare il tuo codice e pianificare i prossimi passi.

Qui puoi monitorare i progressi e configurare il comportamento della tua integrazione. Per una guida completa all'uso di questa dashboard, leggi la nostra specifica sulla Dashboard di Integrazione.
