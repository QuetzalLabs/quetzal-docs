## Integrazione con Quetzal

Una volta che il tuo codebase è connesso con Quetzal, possiamo iniziare a fornire aggiornamenti di localizzazione tramite il controllo del codice sorgente.

## Prerequisiti

Quetzal supporta attualmente solo repository ospitati su GitHub. Verifica che il tuo stack sia supportato consultando i nostri stack supportati.

## Connettere un Repository

Dopo aver [effettuato la registrazione](https://getquetzal.com/signup), puoi [connettere un repository](https://getquetzal.com/onboarding)

Ti verrà chiesto di installare l'app GitHub di Quetzal per concedere accesso a uno o più repository.

Una volta installata, ti verrà chiesto di selezionarne uno per completare l'installazione.

## Selezionare la Directory

Ti verrà chiesto di limitare l'integrazione Quetzal a directory specifiche.

Se hai un repository con più pattern di localizzazione distinti (ad es., un monorepo), è meglio configurare più integrazioni nello stesso repository con directory che non si sovrappongono.

Se il tuo repository ha gli stessi pattern di localizzazione ovunque, puoi lasciare questo campo vuoto.

## Definire i Locale

Ti verrà chiesto di definire quali locale desideri supportare per questa integrazione.

Se i locale sono già definiti nel codebase, puoi selezionare l'opzione "Usa i locale attualmente in uso nel codebase"

Altrimenti, questa è la tua opportunità per definire l'insieme delle lingue.

Questo può essere aggiornato in seguito.

## Prossimi Passi

Ti verrà notificato che la connessione è completa e verrai portato alla [dashboard di integrazione](https://getquetzal.com/dashboard/integration)

Quetzal impiegherà un po' di tempo per esaminare il tuo codice e pianificare i prossimi passi.

Qui puoi monitorare i progressi e configurare il comportamento della tua integrazione. Per una guida completa all'utilizzo di questa dashboard, leggi la nostra specifica della Dashboard di Integrazione.
