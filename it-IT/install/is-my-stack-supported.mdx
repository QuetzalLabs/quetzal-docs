## Checklist

Quetzal è progettato per funzionare con tutti gli stack e tutti i pattern di localizzazione.

Tuttavia, ci sono ancora alcuni requisiti.

## Contenuto Traducibile

Quetzal è pensato per tradurre stringhe statiche definite nel tuo codebase. Per qualsiasi altra cosa, puoi usare la nostra API.

Questo include stringhe UI, documenti di puro testo e altre stringhe definite in file di codice.

Immagini, stringhe generate dall'utente o altre stringhe incontrate a runtime non rientrano nell'ambito di questi strumenti.

## Formati Supportati

Al momento, Quetzal funziona con i seguenti stack:

- Javascript/Typescript
- Next.js/React
- Swift
- Kotlin
- Java
- Python
- HTML/XML
- Documenti di testo (.txt, .mdx, ecc.)

Al momento, NON supportiamo:

- Vue/Svelte

Quetzal è progettato per gestire tutti gli stack in modo elegante. Perciò, se il tuo framework non è nell'elenco ma sei interessato, contattaci pure. Non vediamo l'ora di rendere Quetzal disponibile per il tuo stack.

## Librerie di Traduzione Supportate

Quetzal dovrebbe funzionare con tutte le librerie e i pattern di traduzione.
Tuttavia, Quetzal potrebbe avere difficoltà a gestire gli anti-pattern se il tuo framework di localizzazione è configurato male o mal definito.

Se stai usando un framework di traduzione con capacità limitate, Quetzal potrebbe avere difficoltà a localizzare correttamente dati i vincoli.
I punti ciechi più comuni dei pattern di localizzazione deboli includono:
- Pluralizzazione
- Contenuto dinamico
- Meccanismo fragile di chiavi delle stringhe
- Stringhe frammentate

La maggior parte dei meccanismi di traduzione affidabili gestisce tutto questo senza problemi. Dai un'occhiata ai nostri consigli su [scegliere un framework](/it-IT/install/choosing-a-framework).

Durante la configurazione iniziale, puoi rivedere e aggiornare un file LOCALIZATION.md generato per allineare Quetzal alle pratiche che funzionano meglio per il tuo team.

## File di Testo Grezzo

Il nostro supporto per contenuti tradotti in testo grezzo è attualmente in beta.

Se hai documentazione, articoli di blog o altri file scritti come testo o markdown dove esistono più versioni per ogni lingua, Quetzal potrebbe avere difficoltà ad agganciarsi ai meccanismi richiesti. Monitora attentamente un'integrazione di questo tipo per assicurarti che il comportamento iniziale sia corretto.
