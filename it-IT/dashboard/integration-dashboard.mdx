La Dashboard di Integrazione di Quetzal è una finestra per configurare e monitorare le tue integrazioni.

Puoi accedervi selezionando ["Integrazioni"](https://getquetzal.com/dashboard/integrations) nel menu di navigazione della dashboard principale.

## Gestire la Tua Integrazione

La dashboard di integrazione offre strumenti per configurare le impostazioni e monitorare il lavoro di Quetzal.

Man mano che il tuo codice viene acquisito, le stringhe, le traduzioni e il testo del codice saranno visibili. Le modifiche apportate al contenuto nella dashboard verranno propagate al controllo di versione come configurato.

Le funzionalità di Quetzal possono essere attivate nella scheda Impostazioni Contenuto, e le regole relative a come Quetzal interagisce con il tuo controllo di versione possono essere configurate nella scheda Modifiche.

## Scheda Modifiche

Questo pannello mostra i branch attualmente monitorati e aggiornati da Quetzal.

Ogni branch elencato qui verrà monitorato per le modifiche che influenzano la localizzazione in tempo reale.

Le azioni disponibili:
- Rimuovi: Rimuovi il branch dal monitoraggio. Gli aggiornamenti si fermeranno.
- Ripristina: Annulla qualsiasi elaborazione e rieseguila da zero. Potrebbe essere necessario se le impostazioni sono state modificate ampiamente e l'elaborazione effettuata è diventata obsoleta.

Il pannello delle impostazioni ti permette di definire il comportamento di questi branch.
Si possono impostare regole per elaborare automaticamente i nuovi branch.
Le modifiche possono essere impostate per essere pubblicate tramite pull request, commit diretti, o per niente.
L'opzione "Unisci automaticamente le traduzioni nel branch main in modo indipendente" può essere impostata per unire automaticamente le nuove traduzioni nel main non appena sono pronte.

Per maggiori dettagli sulle modifiche che Quetzal pubblicherà, consulta la nostra documentazione sul commit delle modifiche.

<Tip>
  I nuovi branch possono essere aggiunti in tre modi: Automazione, il pulsante 'Aggiungi Branch', o commentando /quetzal start su una pull request. [Maggiori Informazioni](/it-IT/install/committing-changes)
</Tip>

## Scheda Traduzioni

La scheda Traduzioni ha la stessa struttura della tua scheda traduzioni principale, ma limitata all'integrazione corrente.

I tre pannelli danno accesso in lettura e modifica a:
- Le stringhe nella tua app e le loro traduzioni
- I termini del glossario nella tua app e le loro traduzioni
- Revisioni di traduzione proposte da confermare o rifiutare.

## Impostazioni Contenuto

Questa scheda definisce le impostazioni centrali per il comportamento della tua integrazione Quetzal.

Le funzionalità principali possono essere attivate e disattivate nella prima scheda Generale:
- Esegui traduzioni: Quetzal genererà le traduzioni mancanti. Se disattivato, le stringhe non tradotte resteranno tali.
- Verifica delle traduzioni esistenti: Quetzal proporrà revisioni alle traduzioni esistenti. Se disattivato, le traduzioni esistenti non verranno mai modificate.
- Includi stringhe mancanti: Quetzal modificherà il tuo codice per assicurarsi che tutti i contenuti rivolti all'utente siano tradotti. Se disattivato, il tuo codice non verrà mai modificato.
- Traduci contenuto speciale: Tentativo di tradurre immagini e altri contenuti avanzati (Beta)
- File di Testo: Aggiorna i file di testo localizzati ogni volta che il loro sorgente si aggiorna (Beta)

### Impostazioni Wrapping

Se "Includi stringhe mancanti" è attivato, ulteriori impostazioni determineranno come e quando Quetzal aggiornerà il tuo codice per tradurre le stringhe mancanti.

I tipi di file possono essere elencati per limitare gli aggiornamenti a particolari tipi di file.

Regole di Contenuto: Linee guida fornite all'AI per limitare le stringhe che vengono classificate come da tradurre.

Refactoring: Per impostazione predefinita, faremo un refactoring minimo del tuo codice per assicurare che la localizzazione funzioni. Questo non comporterà mai grandi riscritture, ma piuttosto piccole modifiche come spostare stringhe o aggiungere meccanismi nell'ambito. Puoi disattivarlo o specificare linee guida specifiche.

## Lingua

Definisci in quali lingue tradurre per questa integrazione.

Ci sono anche tre sezioni per aggiungere linee guida che l'AI dovrà considerare:
- Per la traduzione in ciascuna lingua
- Per la traduzione dei termini del glossario
- Per la verifica delle traduzioni esistenti

## Chiavi

Definisci le linee guida per la definizione delle chiavi di traduzione nel tuo codebase.

## Avanzate / LOCALIZATION.md

La scheda Avanzate ti permette di modificare il file LOCALIZATION.md che definisce i pattern di localizzazione seguiti dal codebase.

Viene generato automaticamente alla connessione, ma può essere aggiornato se qualche pattern è errato o incompleto.

Questo documento viene consultato ogni volta che il codice viene aggiornato dall'AI. Se "Includi stringhe mancanti" è disattivato, questo documento è per lo più irrilevante.
