## Instalando

La extensión Quetzal está disponible en el [Mercado de VSCode](https://marketplace.visualstudio.com/items?itemName=QuetzalLabs.com-getquetzal-i18nsetup).

Se puede buscar desde el panel de extensiones en VSCode y Cursor.

## Configuración

Verifica que la configuración de la extensión coincida con tu proyecto. Abre la configuración de VSCode/Cursor y busca Quetzal

Lo más importante es asegurarse de configurar `Quetzal: Biblioteca de traducción` a la biblioteca que estás utilizando para tu proyecto.

## Uso

La extensión Quetzal está diseñada para escribir automáticamente funciones `t` en tu código base de JavaScript.

Añade cuatro comandos a tu Paleta de Comandos de VSCode/Cursor (`Command` + `Shift` + `P` para abrir):

1. Quetzal: Buscar cadenas visibles para el usuario
2. Quetzal: Escanear documento actual
3. Quetzal: Envolver cadenas
4. Quetzal: Detener escaneo

## Ejemplo: Componente simple de Next.js

Supongamos que tienes el siguiente archivo abierto en VSCode/Cursor:

```javascript login.tsx
const LoginPage = () => {
  return (
    <div>
      <h1>Iniciar sesión</h1>
      <form>
        <input type="email" placeholder="Correo electrónico" />
        <input type="password" placeholder="Contraseña" />
        <button type="submit">Iniciar sesión</button>
      </form>
    </div>
  );
};

export default LoginPage;
```

Queremos actualizar esta página de inicio de sesión para que el texto ("Iniciar sesión", "Iniciar sesión", "Correo electrónico" y "Contraseña") esté traducido a todos los idiomas que su proyecto admita.

### Ejecutar análisis

Primero ejecute `Quetzal: Escanear documento actual` (`Command` + `Shift` + `P` para abrir la paleta de comandos)

Tu editor debería verse entonces algo así:

![Extension Highlighting](/images/extension1.png)

El texto resaltado en verde parece ser texto que debería traducirse.

El texto resaltado en rojo parece ser texto que no debe traducirse.

¡Asegúrate de que no hayamos cometido errores! Si algo está en rojo pero debería estar traducido, pasa el cursor por encima y haz clic en `Traduce esta cadena`

Por el contrario, si algo está en verde pero no debe traducirse, pasa el cursor por encima y haz clic en `No traducir esta cadena`

### Envolver Cadenas

Luego, cuando todo parezca correcto, haz clic en `Quetzal: Envolver cadenas` en la parte superior derecha de tu editor de código.

Tu archivo ahora debería verse así:

```javascript login.tsx
import { useI18n } from "@quetzallabs/i18n";

const LoginPage = () => {
  const { t } = useI18n();

  return (
    <div>
      <h1>{t("Iniciar sesión")}</h1>
      <form>
        <input type="email" placeholder={t("Correo electrónico")} />
        <input type="password" placeholder={t("Contraseña")} />
        <button type="submit">{t("Iniciar sesión")}</button>
      </form>
    </div>
  );
};
export default LoginPage;
```

Observa que todo el texto visible para tus usuarios ha sido envuelto en una función `t`, y la función `t` adecuada se ha importado para este componente del lado del cliente.

### ¡Y listo!

Este archivo está ahora marcado, y Quetzal encontrará y traducirá el texto mostrado.

## ¿Qué pasa si tengo muchos archivos?

Si tienes muchos archivos que no se han integrado con Quetzal, ejecuta `Quetzal: Buscar cadenas visibles para el usuario` (`Command` + `Shift` + `P` para abrir la paleta de comandos)

Esto abrirá un menú para escanear varias carpetas de tu proyecto a la vez y ordenar todos los archivos según el número de cadenas que probablemente necesiten traducción.

Esto debería permitirte integrar rápidamente, incluso en una base de código grande.
