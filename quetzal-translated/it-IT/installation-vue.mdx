## Prerequisiti

Quetzal può essere utilizzato per fornire traduzioni per progetti Vue.js che utilizzano il [framework vue-i18n](https://vue-i18n.intlify.dev/)

## Installazione di Quetzal

```_ Installa
npm install --save @quetzallabs/i18n-core
```

## Contattaci

Il supporto per Vue.js è attualmente limitato. Ti preghiamo di [contattarci](https://getquetzal.com/contact) in modo che possiamo aiutarti a impostare una soluzione adatta alle tue esigenze.
