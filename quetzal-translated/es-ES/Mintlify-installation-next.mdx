## Requisitos previos

Quetzal se puede utilizar para traducir Next.js que usa el [framework next-intl](https://next-intl-docs.vercel.app/).

## Instalando Quetzal

```_ Instalar
npm install --save @quetzallabs/i18n-next @quetzallabs/i18n-core
```

## Configuración

Tras instalar el paquete, se requiere configuración adicional.

<Steps>
  <Step title="Ejecutar script de configuración">
    Ejecute `npx quetzal-setup` en el directorio donde instaló el paquete Quetzal
  </Step>
  <Step title="Establecer clave de API">
    Establece la variable de entorno `QUETZAL_API_KEY` con tu Clave de API de Quetzal. Puedes encontrar tu Clave de API en tu [panel de control del proyecto](https://getquetzal.com/dashboard/settings/project/0)
  </Step>
  <Step title="Actualizar quetzal.config.json">
    El script de configuración debería haber creado esto para ti. Actualiza `paths` para que apunte a los directorios con el código que planeas localizar. Actualiza `parser` a `i18next-parser`

    ```js Ejemplo quetzal.config.json
    {
      "paths": ["src/**/*.{js,tsx}"],
      "parser": "i18next-parser"
    }
    ```
  </Step>
  <Step title="Configurar proveedor next-intl">
  Quetzal utiliza el paquete `next-intl` para inyectar traducciones en tu aplicación,
    por lo que tu aplicación necesita usar el `NextIntlClientProvider`

    Esto se verá así:

    ```js

import { NextIntlClientProvider } from "next-intl";
import { getMessages } from "next-intl/server";

const messages = await getMessages();

...

return (

    <html>
        <body>
            <NextIntlClientProvider messages={messages}>
                {children}
            </NextIntlClientProvider>
        </body>
    </html>

);

```
Más detalles sobre este proveedor se pueden encontrar en la [documentación de next-intl](https://next-intl-docs.vercel.app/docs/getting-started).
  </Step>
  <Step title="Configurar el complemento next-intl">
    Tu aplicación también necesita añadir el `NextIntlPlugin` desde `next-intl` en tu archivo next.config.

    <Tabs>
  <Tab title="next.config.mjs">
    ```js
    import createNextIntlPlugin from 'next-intl/plugin';

const withNextIntl = createNextIntlPlugin();

/** @type {import('next').NextConfig} */
const nextConfig = {};

export default withNextIntl(nextConfig);
````

  </Tab>
  <Tab title="next.config.js">
    ```js
const createNextIntlPlugin = require('next-intl/plugin');

const withNextIntl = createNextIntlPlugin();

/\*_ @type {import('next').NextConfig} _/
const nextConfig = {};

module.exports = withNextIntl(nextConfig);

```

  </Tab>
</Tabs>

    Más detalles sobre este plugin se encuentran en la [documentación de next-intl](https://next-intl-docs.vercel.app/docs/getting-started).

  </Step>
</Steps>

## ¡Y listo!

La configuración debería estar completa, y puedes [iniciar la traducción de tu aplicación](/extension).

## Verificar Tu Instalación

Ejecuta `npx quetzal-process-translations` para probar tu instalación.

![Process Translations Output](/images/process-output.png)

Si tu resultado se parece al anterior, entonces Quetzal se ha instalado correctamente y tu aplicación comenzará a admitir otros idiomas.

Si hay errores, esperamos que sean claros y puedan solucionarse. Si no, [contáctenos](https://getquetzal.com/contacto) y podremos hacer que su instalación funcione correctamente.

<Tip>
  Nota: Este script fallará si no ha marcado ningún texto en su aplicación para
  traducir. Por lo tanto, es posible que tenga que [iniciar la traducción de su aplicación](/extension)
  primero
</Tip>

Quetzal está diseñado para integrarse perfectamente en tu proceso de compilación. Por lo tanto, este script debería ejecutarse como mínimo cada vez que se realiza una compilación, pero podría ejecutarse con la frecuencia que desees.

El script de configuración debería haber añadido `npx quetzal-process-translations` al script pre-build en el package.json de tu proyecto, pero esto puede modificarse.
