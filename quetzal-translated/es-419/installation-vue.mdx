## Requisitos previos

Quetzal puede utilizarse para proporcionar traducciones en proyectos Vue.js que usan el [framework vue-i18n](https://vue-i18n.intlify.dev/)

## Instalando Quetzal

```_ Instalar
npm install --save @quetzallabs/i18n-core
```

## Contáctenos

El soporte para Vue.js es limitado en este momento. Por favor [contáctenos](https://getquetzal.com/contact) para ayudarle a configurar una solución que funcione para usted.
