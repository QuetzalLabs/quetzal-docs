## Accediendo al Panel de control del Proyecto

Después de [registrarte](https://getquetzal.com/signup) en Quetzal, se te pedirá crear un proyecto.

Una vez creado tu proyecto, podrás encontrarlo en tu [Panel de control de Quetzal](https://getquetzal.com/dashboard)

<Tip>
  Actualmente, Quetzal es gratuito para traducciones a un idioma/región adicional. Si necesitas soporte para múltiples idiomas o para un idioma no listado, por favor [contáctanos](https://getquetzal.com/contact)
</Tip>

## Uso del panel de control del proyecto

El panel de control es la forma principal de supervisar tus integraciones de Quetzal.

Allí puedes encontrar y gestionar el texto de tu aplicación, y ver todo el texto traducido.

### Cadenas de Proyecto

La pestaña [cadenas del proyecto](https://getquetzal.com/dashboard/strings/project/0) enumera todo el texto que se ha enviado a Quetzal para su traducción.

El texto de la cadena y sus traducciones se pueden ver y editar desde esta página.

Cada cadena también muestra el archivo de tu código fuente donde se encontró (si es aplicable), junto con la fecha en que se añadió.

### Lingo del Proyecto

La pestaña [lingo](https://getquetzal.com/dashboard/lingo/project/0) del proyecto ofrece una forma de indicar palabras o frases especiales únicas de tu marca que deben traducirse de manera particular.

Puedes usar lingo para especificar traducciones personalizadas o evitar que se traduzca una frase en particular.

## Tareas comunes

<AccordionGroup>
  <Accordion title="Encontrar tu Clave de API">
    Tu clave de API se encuentra en tu [página de configuración del proyecto](https://getquetzal.com/panel-de-control/configuracion/proyecto/0). Tu clave de API es importante y se utilizará para la mayoría de las integraciones, y otorga acceso para solicitar y recuperar texto de tu aplicación. La clave es única para tu proyecto y compartida entre todos los usuarios. Asegúrate de mantenerla privada.
  </Accordion>
  <Accordion title="Añadir usuarios">
    La [pestaña de usuarios](https://getquetzal.com/dashboard/users/project/111) te permite invitar a usuarios para acceder y colaborar en tu proyecto de Quetzal.
  </Accordion>
  <Accordion title="Añadir soporte para un idioma">
    Al seleccionar 'Añadir configuración regional' en el lado izquierdo del panel de control, podrás añadir soporte para un nuevo idioma a tu proyecto
  </Accordion>
</AccordionGroup>
