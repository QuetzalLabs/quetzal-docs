## Liste de vérification

Quetzal est conçu pour fonctionner avec toutes les stacks et tous les schémas de localisation.

Cependant, il y a tout de même quelques prérequis.

## Contenu traduisible

Quetzal est destiné à traduire des chaînes statiques définies dans ta base de code. Pour tout le reste, tu peux utiliser notre API.

Cela comprend les chaînes UI, les documents en texte pur, et d'autres chaînes définies dans des fichiers de code.

Les images, les chaînes générées par les utilisateurs, ou d'autres chaînes rencontrées à l'exécution ne font pas partie de la portée de ces outils.

## Formats pris en charge

À l'heure actuelle, Quetzal fonctionne avec les stacks suivantes :

- Javascript/Typescript
- Next.js/React
- Swift
- Kotlin
- Java
- Python
- HTML/XML
- Documents texte (.txt, .mdx, etc.)

Pour l'instant, nous ne prenons PAS en charge :

- Vue/Svelte

Quetzal est conçu pour gérer toutes les stacks avec élégance. Ainsi, si ton framework n'est pas répertorié mais que tu es intéressé, n'hésite pas à nous contacter. Nous avons hâte de faire vivre Quetzal pour ta stack.

## Bibliothèques de traduction prises en charge

Quetzal devrait fonctionner avec toutes les bibliothèques et tous les schémas de traduction.
Cependant, Quetzal peut avoir du mal à gérer les anti-patterns si ton framework de localisation est mal configuré ou mal défini.

Si tu utilises un framework de traduction aux capacités limitées, Quetzal peut avoir du mal à localiser correctement compte tenu des contraintes.
Les angles morts courants des schémas de localisation faibles incluent :
- Pluralisation
- Contenu dynamique
- Mécanisme de clé de chaîne fragile
- Chaînes fragmentées

La plupart des mécanismes de traduction réputés géreront cela très bien. Consulte nos conseils sur [le choix d'un framework](/en-US/install/choosing-a-framework).

Lors de la configuration initiale, tu peux consulter et mettre à jour un fichier LOCALIZATION.md généré pour aligner Quetzal sur les pratiques qui fonctionnent le mieux pour ton équipe.

## Fichiers de texte brut

Notre prise en charge du contenu traduit en texte brut est actuellement en Beta.

Si tu as de la documentation, des articles de blog, ou d'autres fichiers écrits en texte ou markdown où plusieurs versions existent pour chaque locale, Quetzal peut avoir du mal à se connecter aux mécanismes requis. Surveille de près une telle intégration pour t'assurer que le comportement initial est correct.
