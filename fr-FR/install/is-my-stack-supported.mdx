## Checklist

Quetzal est conçu pour fonctionner avec toutes les stacks et tous les modèles de localisation.

Cependant, il y a quand même quelques prérequis.

## Contenu traduisible

Quetzal est fait pour traduire les chaînes statiques définies dans ta base de code. Pour tout le reste, tu peux utiliser notre API.

Ça inclut les chaînes UI, les documents de texte pur, et les autres chaînes définies dans des fichiers de code.

Les images, les chaînes générées par l'utilisateur, ou les autres chaînes rencontrées à l'exécution ne sont pas dans le périmètre de ces outils.

## Formats supportés

Actuellement, Quetzal fonctionne avec les stacks suivantes :

- Javascript/Typescript
- Next.js/React
- Swift
- Kotlin
- Java
- Python
- HTML/XML
- Documents texte (.txt, .mdx, etc.)

Pour le moment, on ne supporte PAS :

- Vue/Svelte

Quetzal est conçu pour gérer toutes les stacks avec élégance. Donc, si ton framework n'est pas listé mais que ça t'intéresse, n'hésite pas à nous contacter. On a hâte de donner vie à Quetzal pour ta stack.

## Bibliothèques de traduction supportées

Quetzal devrait fonctionner avec toutes les bibliothèques et tous les modèles de traduction.
Cependant, Quetzal peut avoir du mal à naviguer les anti-patterns si ton framework de localisation est mal configuré ou mal défini.

Si tu utilises un framework de traduction aux capacités limitées, Quetzal peut avoir du mal à localiser correctement avec ces contraintes.
Les angles morts courants des modèles de localisation faibles incluent :
- Pluralisation
- Contenu dynamique
- Mécanisme fragile de clé de chaîne
- Chaînes fragmentées

La plupart des mécanismes de traduction réputés gèrent ça très bien. Consulte nos conseils pour [choisir un framework](/fr-FR/install/choosing-a-framework).

Pendant la configuration initiale, tu peux consulter et mettre à jour un fichier LOCALIZATION.md généré pour aligner Quetzal avec les pratiques qui fonctionnent le mieux pour ton équipe.

## Fichiers de texte brut

Notre support pour le contenu traduit en texte brut est actuellement en bêta.

Si tu as de la documentation, des articles de blog, ou d'autres fichiers écrits en texte ou markdown où plusieurs versions existent pour chaque locale, Quetzal peut avoir du mal à se brancher sur les mécanismes requis. Surveille une telle intégration de près pour t'assurer que le comportement initial est correct.
