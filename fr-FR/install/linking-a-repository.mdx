## Intégrer Quetzal

Une fois ta base de code liée à Quetzal, nous pouvons commencer à livrer des mises à jour de localisation via le contrôle de source.

## Prérequis

Quetzal ne prend actuellement en charge que les dépôts hébergés sur GitHub. Vérifie que ta stack est prise en charge en consultant nos stacks compatibles.

## Lier un dépôt

Une fois que tu t'es [inscrit](https://getquetzal.com/signup), tu peux [lier un dépôt](https://getquetzal.com/onboarding)

Tu seras invité à installer l'application GitHub Quetzal pour accorder l'accès à un ou plusieurs dépôts.

Une fois l'application installée, tu seras invité à en sélectionner un pour finaliser l'installation.

## Sélection du répertoire

Tu seras invité à définir la portée de l'intégration Quetzal sur des répertoires spécifiques.

Si tu as un dépôt avec plusieurs schémas de localisation distincts (c.-à-d. un monorepo), il est préférable de configurer plusieurs intégrations dans le même dépôt avec des répertoires qui ne se chevauchent pas.

Si ton dépôt utilise uniquement les mêmes schémas de localisation partout, tu peux laisser ce champ vide.

## Définir les locales

Tu seras invité à définir les locales que tu souhaites prendre en charge pour cette intégration.

Si les locales sont déjà définies dans la base de code, tu peux cocher « Utiliser les locales actuellement utilisées dans la base de code »

Sinon, c'est l'occasion de définir l'ensemble des langues.

Cela peut être mis à jour ultérieurement.

## Prochaines étapes

Tu seras informé que la liaison est terminée, et redirigé vers le [tableau de bord d'intégration](https://getquetzal.com/dashboard/integration)

Quetzal prendra un certain temps pour analyser ton code et planifier les prochaines étapes.

Ici, tu peux surveiller la progression et configurer le comportement de ton intégration. Pour un guide complet sur l'utilisation de ce tableau de bord, consulte notre documentation du tableau de bord d'intégration.
