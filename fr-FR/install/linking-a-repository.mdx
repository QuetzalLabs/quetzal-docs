## Intégrer Quetzal

Une fois ta base de code liée à Quetzal, on peut commencer à livrer des mises à jour de localisation via le contrôle de version.

## Prérequis

Quetzal ne supporte actuellement que les dépôts hébergés sur GitHub. Vérifie que ta stack est supportée en consultant nos stacks supportées.

## Lier un dépôt

Une fois que tu t'es [inscrit](https://getquetzal.com/signup), tu peux [lier un dépôt](https://getquetzal.com/onboarding)

Tu seras invité à installer l'application GitHub Quetzal pour accorder l'accès à un ou plusieurs dépôts.

Une fois installée, tu seras invité à en sélectionner un pour finaliser l'installation.

## Sélection du répertoire

Tu seras invité à limiter l'intégration Quetzal à des répertoires spécifiques.

Si tu as un repo avec plusieurs modèles de localisation distincts (par ex., un monorepo), il est préférable de configurer plusieurs intégrations dans le même repo avec des répertoires qui ne se chevauchent pas.

Si ton dépôt n'a que les mêmes modèles de localisation partout, tu peux laisser ce champ vide.

## Définition des locales

Tu seras invité à définir quelles locales tu souhaites supporter pour cette intégration.

Si les locales sont déjà définies dans la base de code, tu peux cocher « Utilise les locales actuellement présentes dans ta base de code »

Sinon, c'est l'occasion de définir l'ensemble des langues.

Ça peut être mis à jour plus tard.

## Prochaines étapes

Tu seras informé que la liaison est terminée et redirigé vers le [tableau de bord d'intégration](https://getquetzal.com/dashboard/integration)

Quetzal prendra un peu de temps pour analyser ton code et planifier les prochaines étapes.

Ici, tu peux surveiller la progression et configurer le comportement de ton intégration. Pour un guide complet d'utilisation de ce tableau de bord, consulte notre spécification du Tableau de bord d'intégration.
