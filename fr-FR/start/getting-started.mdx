## Bienvenue sur Quetzal !

Cette documentation te guidera pour mettre en place et utiliser Quetzal avec ta stack.

## Localisation de la base de code

Quetzal est conçu pour maintenir la localisation du contenu statique dans ton application.
L'intégration fonctionne un peu différemment selon l'état actuel de ton code :

<Card title="Aucune localisation" icon="sprout" href="/en-US/start/first-time-localization">
  Aucun contenu dans ma base de code n'est traduit, et je cherche à commencer
</Card>
<Card title="Localisation partielle" icon="form" href="/en-US/start/existing-localization">
  Il y a un système de localisation, mais il n'est pas beaucoup utilisé, voire pas du tout.
</Card>
<Card title="Localisation étendue" icon="form" href="/en-US/existing-localization">
  Il y a déjà un système de localisation et il est largement utilisé.
</Card>

## Localisation du contenu généré

Pour traduire le contenu non statique (contenu généré par l'utilisateur, contenu généré à l'exécution), notre API est disponible.

Parle avec nous pour t'assurer que le profil d'utilisation est bien adapté à Quetzal.

### Étapes d'intégration

L'intégration se fait généralement en quatre étapes :

<Steps>
  <Step title="Lie ton dépôt">
    [Inscris-toi](https://getquetzal.com/signup) sur Quetzal et tu seras invité à installer l'application GitHub de Quetzal. Si tu as déjà un compte, tu peux [lier un dépôt directement](https://getquetzal.com/onboarding)
  </Step>
  <Step title="Attends l'analyse">
    Notre analyse initiale et synchronisation détermineront la compatibilité.
  </Step>
  <Step title="Mets à jour les paramètres">
    Utilise le [Tableau de bord d'intégration](https://getquetzal.com/dashboard) pour confirmer les paramètres.
  </Step>
  <Step title="Fusionne les modifications">
    À l'avenir, les mises à jour de localisation seront publiées sur git via des pull requests ou des commits directs
  </Step>
</Steps>
