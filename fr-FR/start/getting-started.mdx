## Bienvenue chez Quetzal !

Cette documentation te guidera dans la configuration et l'utilisation de Quetzal avec ta stack.

## Localisation de la base de code

Quetzal est conçu pour maintenir la localisation du contenu statique de ton application.
L'intégration fonctionne un peu différemment selon l'état actuel de ton code :

<Card title="Aucune localisation" icon="sprout" href="/en-US/start/first-time-localization">
  Aucun contenu dans ma base de code n'est traduit, et je cherche à démarrer
</Card>
<Card title="Localisation partielle" icon="form" href="/en-US/start/existing-localization">
  Il existe un système de localisation, mais il est peu ou pas du tout utilisé.
</Card>
<Card title="Localisation étendue" icon="form" href="/en-US/existing-localization">
  Il existe déjà un système de localisation et il est largement utilisé.
</Card>

## Localisation du contenu généré

Pour traduire le contenu non statique (contenu généré par les utilisateurs, contenu généré à l'exécution), notre API est disponible.

Parle avec nous pour t'assurer que le profil d'utilisation est bien adapté à Quetzal.

### Étapes d'intégration

L'intégration prend généralement quatre étapes :

<Steps>
  <Step title="Lier ton dépôt">
    [Inscris-toi](https://getquetzal.com/signup) sur Quetzal et tu seras invité à installer l'application GitHub Quetzal. Si tu as déjà un compte, tu peux [lier un dépôt directement](https://getquetzal.com/onboarding)
  </Step>
  <Step title="Attendre l'analyse">
    Notre analyse et synchronisation initiales détermineront la compatibilité.
  </Step>
  <Step title="Mettre à jour les paramètres">
    Utilise le [tableau de bord d'intégration](https://getquetzal.com/dashboard) pour confirmer les paramètres.
  </Step>
  <Step title="Fusionner les modifications">
    À partir de maintenant, les mises à jour de localisation seront publiées dans git via des pull requests ou des commits directs
  </Step>
</Steps>
