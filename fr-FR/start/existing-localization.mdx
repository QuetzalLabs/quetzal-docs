## Intégrer Quetzal

Si ta base de code dispose d'un système de localisation existant, Quetzal peut le maintenir à l'avenir.

Quetzal se conformera à tes pratiques existantes pour mettre à jour et auditer la localisation.

Tu peux commencer par [lier ta base de code](/fr-FR/install/linking-a-repository). Cela créera une intégration pour fournir des mises à jour de localisation à ton code via git.

## Que fera Quetzal ?

Une fois lié, Quetzal traduira le contenu futur, vérifiera la qualité des traductions existantes et mettra à jour ton code pour garantir une couverture de traduction complète.

Cette intégration ne supporte actuellement que le contenu statique. Le contenu généré à l'exécution, traduit ou non, ne sera pas affecté par cette intégration. Pour traduire le contenu à l'exécution, tu peux utiliser ton API.

Les fonctionnalités peuvent être activées ou désactivées dans les paramètres une fois qu'un dépôt est lié.

## Compatibilité

Pour t'assurer que ta stack fonctionne avec Quetzal à l'avance, tu peux [vérifier la compatibilité avec Quetzal](/fr-FR/install/is-my-stack-supported).
