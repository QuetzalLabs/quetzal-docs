<Tip>
  Petite info : Pour les applications Swift, aucune localisation existante n'est nécessaire pour localiser avec Quetzal. Swift possède des schémas de localisation standardisés qui seront respectés.
</Tip>

## Configurer la localisation

Quetzal s'intègre à tes schémas de localisation existants, mais il ne les fournit, installe ni configure pour toi.

Avant de lier ta base de code à Quetzal, tu devrais commencer par mettre en place un système de localisation et traduire quelques chaînes pour tester.

Quetzal s'occupera du reste. Une fois que le travail de base pour une localisation est dans ton code, tu peux passer à [lier ta base de code](/en-US/install/linking-a-repository).

## Ressources

Pour t'aider à choisir un schéma de localisation adapté à ta base de code, tu peux consulter [nos conseils](/en-US/install/choosing-a-framework).
