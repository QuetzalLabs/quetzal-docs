Le tableau de bord d'intégration de Quetzal est une fenêtre pour configurer et surveiller tes intégrations.

Il est accessible en sélectionnant ["Intégrations"](https://getquetzal.com/dashboard/integrations) dans le menu de navigation du tableau de bord principal.

## Gérer ton intégration

Le tableau de bord d'intégration offre des outils pour configurer les paramètres et surveiller le travail de Quetzal.

Au fur et à mesure que ton code est ingéré, les chaînes, traductions et textes du code seront visibles. Les modifications apportées au contenu dans le tableau de bord seront propagées vers le contrôle de source tel que configuré.

Les fonctionnalités de Quetzal peuvent être activées ou désactivées sous l'onglet Paramètres de contenu, et les règles concernant la façon dont Quetzal interagit avec ton contrôle de source peuvent être configurées sous l'onglet Modifications.

## Onglet Modifications

Ce panneau affiche les branches actuellement surveillées et mises à jour par Quetzal.

Chaque branche listée ici sera surveillée pour détecter les modifications affectant la localisation en temps réel.

Les actions disponibles :
- Supprimer : Retire la branche de la surveillance. Les mises à jour s'arrêteront.
- Réinitialiser : Annule tout le traitement et le relance depuis le début. Cela peut être nécessaire si les paramètres ont été modifiés de façon importante et que le traitement effectué est devenu obsolète.

Le panneau de paramètres te permet de définir le comportement de ces branches.
Des règles peuvent être configurées pour traiter automatiquement les nouvelles branches.
Les modifications peuvent être définies pour être publiées via pull request, des commits directs, ou pas du tout.
L'option "Fusionner automatiquement les traductions dans la branche principale de façon indépendante" peut être définie pour fusionner automatiquement les nouvelles traductions dans main dès qu'elles sont prêtes.

Pour plus de détails sur les modifications que Quetzal va publier, consulte notre documentation sur la validation des modifications.

<Tip>
  Les nouvelles branches peuvent être ajoutées de trois façons : l'automatisation, le bouton 'Ajouter une branche', ou en commentant /quetzal start sur une pull request. [Plus d'informations](/en-US/install/committing-changes)
</Tip>

## Onglet Traductions

L'onglet traductions a la même structure que ton onglet traductions principal, mais limité à l'intégration actuelle.

Les trois panneaux donnent accès en lecture et en modification à :
- Les chaînes de ton application et leurs traductions
- Les termes du glossaire de ton application et leurs traductions
- Les révisions de traduction proposées à confirmer ou rejeter.

## Paramètres de contenu

Cet onglet définit les paramètres essentiels au comportement de ton intégration Quetzal.

L'ensemble des fonctionnalités principales peut être activé ou désactivé dans le premier onglet Général :
- Effectuer les traductions : Quetzal générera les traductions manquantes. Si cette option est désactivée, les chaînes non traduites resteront ainsi.
- Auditer les traductions existantes : Quetzal proposera des révisions aux traductions existantes. Si cette option est désactivée, les traductions existantes ne seront jamais modifiées.
- Envelopper les chaînes manquantes : Quetzal modifiera ton code pour s'assurer que tout le contenu visible par l'utilisateur est traduit. Si cette option est désactivée, ton code ne sera jamais modifié.
- Traduire le contenu spécial : Tente de traduire les images et autres contenus avancés (Beta)
- Fichiers texte : Met à jour les fichiers texte localisés dès que leur source est mise à jour (Beta)

### Paramètres d'enveloppement

Si "Envelopper les chaînes manquantes" est activé, d'autres paramètres détermineront comment et quand Quetzal mettra à jour ton code pour traduire les chaînes manquantes.

Les types de fichiers peuvent être listés pour limiter les mises à jour à des types de fichiers particuliers.

Règles de contenu : Instructions fournies à l'IA pour limiter les chaînes qui finissent par être classifiées comme nécessitant une traduction.

Refactoring : Par défaut, nous refactoriserons ton code de façon minimale pour garantir que la localisation fonctionne. Cela n'impliquera jamais de réécriture importante, mais plutôt de petites modifications comme déplacer des chaînes ou ajouter des mécanismes dans la portée. Tu peux désactiver cette option, ou spécifier des instructions spécifiques.

## Langue

Définis les locales dans lesquelles traduire pour cette intégration.

Il y a aussi trois sections pour ajouter des instructions que l'IA doit prendre en compte :
- Pour traduire dans chaque locale
- Pour traduire les termes du glossaire
- Pour auditer les traductions existantes

## Clés

Définis des instructions pour définir les clés de traduction dans ta base de code.

## Avancé / LOCALIZATION.md

L'onglet avancé te permet de modifier le fichier LOCALIZATION.md qui définit les schémas de localisation auxquels la base de code adhère.

Ceci est généré automatiquement lors de la liaison, mais peut être mis à jour si des schémas sont incorrects ou incomplets.

Ce document est consulté chaque fois que le code est mis à jour par l'IA. Si "Envelopper les chaînes manquantes" est désactivé, ce document est en grande partie sans intérêt.
