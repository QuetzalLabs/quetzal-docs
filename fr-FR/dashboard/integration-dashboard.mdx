Le Tableau de bord d'intégration de Quetzal est une interface pour configurer et surveiller tes intégrations.

Tu peux y accéder en sélectionnant [« Intégrations »](https://getquetzal.com/dashboard/integrations) dans le menu de navigation du tableau de bord principal.

## Gérer ton intégration

Le tableau de bord d'intégration propose des outils pour configurer les paramètres et surveiller le travail de Quetzal.

Au fur et à mesure que ton code est analysé, les chaînes, traductions et textes du code seront visibles. Les modifications apportées au contenu dans le tableau de bord seront propagées au contrôle de source selon la configuration.

Les fonctionnalités de Quetzal peuvent être activées ou désactivées dans l'onglet Paramètres de contenu, et les règles concernant la façon dont Quetzal interagit avec ton contrôle de source peuvent être configurées dans l'onglet Modifications.

## Onglet Modifications

Ce panneau montre les branches actuellement surveillées et mises à jour par Quetzal.

Chaque branche listée ici sera surveillée en temps réel pour détecter les changements qui affectent la localisation.

Les actions disponibles :
- Supprimer : Retirer la branche de la surveillance. Les mises à jour s'arrêteront.
- Réinitialiser : Annuler tout traitement et le relancer à zéro. Cela peut être nécessaire si les paramètres ont été modifiés de manière importante et que le traitement effectué est devenu obsolète.

Le panneau de paramètres te permet de définir le comportement de ces branches.
Des règles peuvent être mises en place pour traiter automatiquement les nouvelles branches.
Les modifications peuvent être configurées pour être publiées via pull request, commits directs, ou pas du tout.
L'option « Fusionner automatiquement les traductions dans la branche main de façon indépendante » peut être activée pour fusionner automatiquement les nouvelles traductions dans main dès qu'elles sont prêtes.

Pour plus de détails sur les modifications que Quetzal va publier, consulte notre documentation sur la validation des modifications.

<Tip>
  De nouvelles branches peuvent être ajoutées de trois façons : l'automatisation, le bouton « Ajouter une branche », ou en commentant /quetzal start sur une pull request. [Plus d'informations](/fr-FR/install/committing-changes)
</Tip>

## Onglet Traductions

L'onglet traductions a la même structure que ton onglet traductions principal, mais limité à l'intégration actuelle.

Les trois panneaux donnent un accès en lecture et modification à :
- Les chaînes de ton application et leurs traductions
- Les termes du glossaire de ton application et leurs traductions
- Les révisions de traduction proposées à confirmer ou rejeter.

## Paramètres de contenu

Cet onglet définit les paramètres essentiels au comportement de ton intégration Quetzal.

L'ensemble des fonctionnalités principales peut être activé et désactivé dans le premier onglet Général :
- Effectuer des traductions : Quetzal générera les traductions manquantes. Si cette option est désactivée, les chaînes non traduites resteront telles quelles.
- Auditer les traductions existantes : Quetzal proposera des révisions aux traductions existantes. Si cette option est désactivée, les traductions existantes ne seront jamais modifiées.
- Encapsuler les chaînes manquantes : Quetzal modifiera ton code pour s'assurer que tout le contenu visible par l'utilisateur est traduit. Si cette option est désactivée, ton code ne sera jamais modifié.
- Traduis le contenu spécial : Essai de traduction des images et autres contenus avancés (Bêta)
- Fichiers texte : Mise à jour des fichiers texte localisés lorsque leur source est modifiée (Bêta)

### Paramètres d'encapsulation

Si « Encapsuler les chaînes manquantes » est activé, des paramètres supplémentaires détermineront comment et quand Quetzal mettra à jour ton code pour traduire les chaînes manquantes.

Les types de fichiers peuvent être listés pour limiter les mises à jour à des types de fichiers particuliers.

Règles de contenu : Directives fournies à l'IA pour limiter les chaînes qui finissent par être classées comme nécessitant une traduction.

Refactoring : Par défaut, nous refactoriserons ton code de manière minimale pour garantir le fonctionnement de la localisation. Cela n'impliquera jamais de grosses réécritures, mais plutôt de petites modifications comme le déplacement de chaînes ou l'ajout de mécanismes dans le périmètre. Tu peux désactiver cette option ou définir des directives spécifiques.

## Langue

Définis dans quelles langues traduire pour cette intégration.

Il y a également trois sections pour ajouter des directives que l'IA prendra en compte :
- Pour la traduction dans chaque langue
- Pour la traduction des termes du glossaire
- Pour l'audit des traductions existantes

## Clés

Définis des directives pour définir les clés de traduction dans ton code.

## Avancé / LOCALIZATION.md

L'onglet Avancé te permet de modifier le fichier LOCALIZATION.md qui définit les patterns de localisation auxquels le code se conforme.

Ce fichier est généré automatiquement lors de la liaison, mais il peut être mis à jour si des patterns sont incorrects ou incomplets.

Ce document est consulté chaque fois que le code est mis à jour par l'IA. Si « Encapsuler les chaînes manquantes » est désactivé, ce document n'est plus vraiment pertinent.
