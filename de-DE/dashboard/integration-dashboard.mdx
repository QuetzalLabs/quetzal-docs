Das Quetzal Integrations-Dashboard ist eine Oberfläche zum Konfigurieren und Überwachen deiner Integrationen.

Du erreichst es, indem du ["Integrationen"](https://getquetzal.com/dashboard/integrations) im Navigationsmenü des Haupt-Dashboards auswählst.

## Deine Integration verwalten

Das Integrations-Dashboard bietet Tools zum Konfigurieren von Einstellungen und zum Überwachen der Arbeit von Quetzal.

Während dein Code erfasst wird, werden Strings, Übersetzungen und Texte aus dem Code sichtbar. Änderungen an Inhalten im Dashboard werden wie konfiguriert an die Versionsverwaltung weitergegeben.

Quetzal-Features können unter dem Tab Content-Einstellungen ein- und ausgeschaltet werden, und die Regeln für die Interaktion von Quetzal mit deiner Versionsverwaltung können unter dem Tab Änderungen konfiguriert werden.

## Tab Änderungen

Dieses Panel zeigt die Branches, die derzeit von Quetzal überwacht und aktualisiert werden.

Jeder hier aufgeführte Branch wird in Echtzeit auf Änderungen überwacht, die die Lokalisierung betreffen.

Die verfügbaren Aktionen:
- Entfernen: Den Branch aus der Überwachung entfernen. Updates werden gestoppt.
- Zurücksetzen: Jegliche Verarbeitung zurücksetzen und neu starten. Das kann nötig sein, wenn Einstellungen umfangreich geändert wurden und die bisherige Verarbeitung veraltet ist.

Im Einstellungsbereich kannst du das Verhalten dieser Branches festlegen.
Es können Regeln eingerichtet werden, um neue Branches automatisch zu verarbeiten.
Änderungen können so konfiguriert werden, dass sie per Pull Request, direktem Commit oder gar nicht veröffentlicht werden.
Die Option „Übersetzungen automatisch unabhängig in den Main-Branch mergen" kann aktiviert werden, um neue Übersetzungen automatisch in main zu mergen, sobald sie fertig sind.

Weitere Details zu den Änderungen, die Quetzal veröffentlichen wird, findest du in unserer Dokumentation zum Committen von Änderungen.

<Tip>
  Neue Branches können auf drei Wegen hinzugefügt werden – per Automatisierung, über den Button „Branch hinzufügen" oder indem du /quetzal start auf einem Pull Request kommentierst. [Weitere Informationen](/de-DE/install/committing-changes)
</Tip>

## Tab Übersetzungen

Der Tab Übersetzungen hat dieselbe Struktur wie dein Haupt-Tab für Übersetzungen, ist aber auf die aktuelle Integration beschränkt.

Die drei Bereiche bieten dir Lese- und Schreibzugriff auf:
- Strings in deiner App und deren Übersetzungen
- Glossar-Begriffe in deiner App und deren Übersetzungen
- Vorgeschlagene Überarbeitungen von Übersetzungen zum Bestätigen oder Ablehnen.

## Content-Einstellungen

Dieser Tab definiert die zentralen Einstellungen für das Verhalten deiner Quetzal-Integration.

Die wichtigsten Features können im ersten Tab Allgemein ein- und ausgeschaltet werden:
- Übersetzungen durchführen: Quetzal generiert fehlende Übersetzungen. Wenn dies deaktiviert ist, bleiben unübersetzte Strings unübersetzt.
- Bestehende Übersetzungen überprüfen: Quetzal schlägt Überarbeitungen bestehender Übersetzungen vor. Wenn dies deaktiviert ist, werden bestehende Übersetzungen nie geändert.
- Fehlende Strings wrappen: Quetzal ändert deinen Code, um sicherzustellen, dass alle nutzersichtigen Inhalte übersetzt werden. Wenn dies deaktiviert ist, wird dein Code nie geändert.
- Übersetze spezielle Inhalte: Versucht, Bilder und andere erweiterte Inhalte zu übersetzen (Beta)
- Textdateien: Aktualisiert lokalisierte Textdateien, wenn deren Quelle aktualisiert wird (Beta)

### Wrapping-Einstellungen

Wenn „Fehlende Strings wrappen" aktiviert ist, bestimmen weitere Einstellungen, wie und wann Quetzal deinen Code aktualisiert, um fehlende Strings zu übersetzen.

Dateitypen können aufgelistet werden, um Aktualisierungen auf bestimmte Dateitypen einzuschränken.

Content-Regeln: Richtlinien für die KI, um einzuschränken, welche Strings als übersetzungsbedürftig eingestuft werden.

Refactoring: Standardmäßig refactoren wir deinen Code minimal, um sicherzustellen, dass die Lokalisierung funktioniert. Das beinhaltet nie große Umschreibungen, sondern kleine Änderungen wie das Verschieben von Strings oder das Hinzufügen von Mechanismen im Scope. Du kannst dies deaktivieren oder eigene Richtlinien festlegen.

## Sprache

Lege fest, in welche Locales für diese Integration übersetzt werden soll.

Es gibt außerdem drei Bereiche, um Richtlinien für die KI hinzuzufügen:
- Für die Übersetzung in jede Locale
- Für die Übersetzung von Glossar-Begriffen
- Für das Überprüfen bestehender Übersetzungen

## Schlüssel

Lege Richtlinien für die Definition von Übersetzungsschlüsseln in deiner Codebasis fest.

## Erweitert / LOCALIZATION.md

Der Tab Erweitert ermöglicht es dir, die LOCALIZATION.md-Datei zu bearbeiten, die die Lokalisierungsmuster definiert, an die sich die Codebasis hält.

Diese wird beim Verknüpfen automatisch generiert, kann aber aktualisiert werden, falls Muster fehlerhaft oder unvollständig sind.

Dieses Dokument wird herangezogen, wenn Code durch KI aktualisiert wird. Wenn „Fehlende Strings wrappen" deaktiviert ist, ist dieses Dokument größtenteils irrelevant.
