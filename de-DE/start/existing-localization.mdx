## Integration mit Quetzal

Wenn deine Codebasis ein vorhandenes Lokalisierungssystem hat, kann Quetzal es zukünftig pflegen.

Quetzal hält sich an deine bestehenden Praktiken, um die Lokalisierung zu aktualisieren und zu überprüfen.

Du kannst beginnen, indem du [deine Codebasis verknüpfst](/de-DE/install/linking-a-repository). Dadurch wird eine Integration erstellt, die Lokalisierungsupdates per Git an deinen Code liefert.

## Was wird Quetzal tun?

Sobald verknüpft, wird Quetzal zukünftige Inhalte übersetzen, die Qualität bestehender Übersetzungen überprüfen und deinen Code aktualisieren, um vollständige Übersetzungsabdeckung sicherzustellen.

Diese Integration unterstützt derzeit nur statische Inhalte. Inhalte, die zur Laufzeit generiert werden, ob übersetzt oder nicht, werden durch diese Integration nicht beeinflusst. Um Laufzeit-Inhalte zu übersetzen, kannst du deine API verwenden.

Features können in den Einstellungen ein- und ausgeschaltet werden, sobald ein Repository verknüpft ist.
