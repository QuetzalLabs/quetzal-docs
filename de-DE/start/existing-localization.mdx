## Integration mit Quetzal

Wenn deine Codebase ein bestehendes Lokalisierungssystem hat, kann Quetzal es von nun an pflegen.

Quetzal hält sich an deine bestehenden Praktiken, um Lokalisierungen zu aktualisieren und zu prüfen.

Du kannst damit beginnen, [deine Codebase zu verknüpfen](/en-US/install/linking-a-repository). Dadurch wird eine Integration erstellt, die Lokalisierungs-Updates über Git an deinen Code liefert.

## Was wird Quetzal tun?

Sobald verknüpft, wird Quetzal zukünftige Inhalte übersetzen, die Qualität bestehender Übersetzungen prüfen und deinen Code aktualisieren, um eine vollständige Übersetzungsabdeckung sicherzustellen.

Diese Integration unterstützt derzeit nur statische Inhalte. Zur Laufzeit generierte Inhalte, ob übersetzt oder nicht, werden von dieser Integration nicht betroffen. Um Laufzeitinhalte zu übersetzen, kannst du deine API verwenden.

Funktionen können in den Einstellungen aktiviert oder deaktiviert werden, sobald ein Repository verknüpft ist.

## Kompatibilität

Um sicherzustellen, dass dein Stack vorab mit Quetzal funktioniert, kannst du [die Kompatibilität mit Quetzal prüfen](/en-US/install/is-my-stack-supported).
