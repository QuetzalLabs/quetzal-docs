Quetzal veröffentlicht Änderungen an deiner Codebase über die Versionsverwaltung.

Zeitpunkt und Struktur der Änderungen können so eingerichtet werden, dass sie am besten zum Workflow deines Teams passen.

## Was wird veröffentlicht?

Neue Übersetzungen, Übersetzungen

- Neue Übersetzungen
- Überarbeitungen von Übersetzungen
- Code-Updates für die Lokalisierungsabdeckung

Diese Funktionen können in den Einstellungen deiner Integration ein- und ausgeschaltet werden.

## Wie Änderungen veröffentlicht werden

Änderungen werden via Github-Commits in deine Codebase eingespielt.

Standardmäßig werden Änderungen über einen einzelnen, auf Lokalisierung ausgerichteten Pull Request in einen einzelnen Branch veröffentlicht.

Du kannst dies ändern, um stattdessen per direkten Commits zu veröffentlichen

## Aktive Branches

Standardmäßig überwacht Quetzal nur einen einzelnen Branch und veröffentlicht Änderungen daran.

Du kannst neue Branches zum Verfolgen hinzufügen, indem du einen Filter festlegst, welche neuen Branches verarbeitet werden sollen, oder indem du Quetzal in den Kommentaren eines Pull Requests aufrufst.

Branches können auch manuell über das Dashboard hinzugefügt werden.

Aktive Branches werden von Quetzal in Echtzeit verarbeitet und aktualisiert, sodass die Lokalisierung stets auf dem neuesten Stand ist.


## Reiner Übersetzungs-Branch

Du hast die Möglichkeit, Übersetzungs-Updates von anderen Code-Updates zu trennen.

Das würde es ermöglichen, Übersetzungsänderungen automatisch in main zu mergen, während andere Code-Änderungen über ein anderes Muster veröffentlicht werden.

## Manuelle Updates

Wenn du deine Codebase lieber manuell aktualisieren möchtest, kannst du Änderungen stattdessen über unsere API abrufen.

Änderungen können abgefragt und eigenständig in deinen Workflow integriert werden, um maximale Kontrolle zu erhalten.
