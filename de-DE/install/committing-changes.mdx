Quetzal veröffentlicht Änderungen an deiner Codebasis über die Versionskontrolle.

Zeitpunkt und Struktur der Änderungen lassen sich so einrichten, dass sie optimal zum Workflow deines Teams passen.

## Was wird veröffentlicht?

Neue Übersetzungen, Übersetzungen

- Neue Übersetzungen
- Übersetzungsrevisionen
- Code-Updates für die Lokalisierungsabdeckung

Diese Funktionen können in den Einstellungen deiner Integration ein- und ausgeschaltet werden.

## Wie Änderungen veröffentlicht werden

Änderungen werden über GitHub-Commits in deine Codebasis übernommen.

Standardmäßig werden Änderungen über einen einzelnen, auf Lokalisierung ausgerichteten Pull Request in einen einzelnen Branch veröffentlicht.

Du kannst das ändern und stattdessen per direkten Commits veröffentlichen

## Aktive Branches

Standardmäßig überwacht Quetzal nur einen einzelnen Branch und veröffentlicht Änderungen dorthin.

Du kannst neue Branches zum Verfolgen hinzufügen, indem du einen Filter festlegst, welche neuen Branches verarbeitet werden sollen, oder indem du Quetzal in den Kommentaren eines Pull Requests aufrufst.

Branches können auch manuell über das Dashboard hinzugefügt werden.

Aktive Branches werden von Quetzal in Echtzeit verarbeitet und aktualisiert, sodass die Lokalisierung immer auf dem neuesten Stand ist.


## Reiner Übersetzungs-Branch

Du hast die Möglichkeit, Übersetzungsupdates von anderen Code-Updates zu trennen.

So können Übersetzungsänderungen automatisch in main gemergt werden, während andere Code-Änderungen über ein anderes Muster veröffentlicht werden.

## Manuelle Updates

Wenn du deine Codebasis lieber manuell aktualisieren möchtest, kannst du Änderungen stattdessen über unsere API abrufen. 

Änderungen können abgefragt und eigenständig in deinen Workflow eingearbeitet werden – für maximale Kontrolle.
