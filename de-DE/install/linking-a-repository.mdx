## Integration mit Quetzal

Sobald deine Codebasis mit Quetzal verknüpft ist, können wir damit beginnen, Lokalisierungsupdates über die Versionskontrolle bereitzustellen.

## Voraussetzungen

Quetzal unterstützt derzeit nur auf GitHub gehostete Repositories. Prüfe, ob dein Stack unterstützt wird, indem du dir unsere unterstützten Stacks anschaust.

## Ein Repository verknüpfen

Sobald du dich [angemeldet hast](https://getquetzal.com/signup), kannst du [ein Repository verknüpfen](https://getquetzal.com/onboarding)

Du wirst aufgefordert, die Quetzal GitHub App zu installieren, um Zugriff auf ein oder mehrere Repositories zu gewähren.

Nach der Installation wirst du aufgefordert, eines auszuwählen, um die Installation abzuschließen.

## Verzeichnis auswählen

Du wirst aufgefordert, die Quetzal-Integration auf bestimmte Verzeichnisse einzugrenzen.

Wenn du ein Repo mit mehreren unterschiedlichen Lokalisierungsmustern hast (z. B. ein Monorepo), ist es am besten, mehrere Integrationen im selben Repo mit Verzeichnissen einzurichten, die sich nicht überlappen.

Wenn dein Repository durchgehend die gleichen Lokalisierungsmuster hat, kannst du das leer lassen.

## Locales definieren

Du wirst aufgefordert zu definieren, welche Locales du für diese Integration unterstützen möchtest.

Wenn die Locales bereits in der Codebasis definiert sind, kannst du „Verwende Locales, die aktuell in der Codebase verwendet werden" anhaken

Andernfalls hast du hier die Möglichkeit, die Sprachen festzulegen.

Das kann später aktualisiert werden.

## Nächste Schritte

Du wirst darüber informiert, dass die Verknüpfung abgeschlossen ist, und zum [Integrations-Dashboard](https://getquetzal.com/dashboard/integration) weitergeleitet

Quetzal wird sich etwas Zeit nehmen, um deinen Code zu überprüfen und die nächsten Schritte zu planen.

Hier kannst du den Fortschritt überwachen und das Verhalten deiner Integration konfigurieren. Für eine vollständige Anleitung zur Nutzung dieses Dashboards lies unsere Spezifikation zum Integrations-Dashboard.
