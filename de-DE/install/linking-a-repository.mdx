## Integration mit Quetzal

Sobald deine Codebase mit Quetzal verknüpft ist, können wir mit der Auslieferung von Lokalisierungs-Updates über die Versionsverwaltung beginnen.

## Voraussetzungen

Quetzal unterstützt derzeit nur auf GitHub gehostete Repositories. Überprüfe, ob dein Stack unterstützt wird, indem du unsere unterstützten Stacks liest.

## Ein Repository verknüpfen

Sobald du dich [angemeldet hast](https://getquetzal.com/signup), kannst du [ein Repository verknüpfen](https://getquetzal.com/onboarding)

Du wirst aufgefordert, die Quetzal GitHub App zu installieren, um Zugriff auf ein oder mehrere Repositories zu gewähren.

Nach der Installation wirst du aufgefordert, eines auszuwählen, um die Installation abzuschließen.

## Verzeichnis auswählen

Du wirst aufgefordert, die Quetzal-Integration auf bestimmte Verzeichnisse einzuschränken.

Wenn dein Repo mehrere unterschiedliche Lokalisierungsmuster hat (z. B. ein Monorepo), ist es am besten, mehrere Integrationen im selben Repo mit nicht überlappenden Verzeichnissen einzurichten.

Wenn dein Repository durchgehend dieselben Lokalisierungsmuster verwendet, kannst du dies leer lassen.

## Locales festlegen

Du wirst aufgefordert, festzulegen, welche Locales du für diese Integration unterstützen möchtest.

Wenn die Locales bereits in der Codebase definiert sind, kannst du „Use locales currently in use in the codebase" abhaken.

Andernfalls ist dies deine Gelegenheit, die Sprachauswahl festzulegen.

Das kann später noch aktualisiert werden.

## Nächste Schritte

Du wirst darüber informiert, dass die Verknüpfung abgeschlossen ist, und zum [Integrations-Dashboard](https://getquetzal.com/dashboard/integration) weitergeleitet.

Quetzal wird etwas Zeit benötigen, um deinen Code zu analysieren und die nächsten Schritte zu planen.

Hier kannst du den Fortschritt überwachen und das Verhalten deiner Integration konfigurieren. Eine vollständige Anleitung zur Nutzung dieses Dashboards findest du in unserer Integrations-Dashboard-Spezifikation.
