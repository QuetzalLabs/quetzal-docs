## Accediendo al Panel de Control del Proyecto

Después de [registrarte](https://getquetzal.com/signup) en Quetzal, se te pedirá crear un proyecto.

Una vez que se cree tu proyecto, puedes encontrarlo en tu [Panel de Control de Quetzal](https://getquetzal.com/dashboard)

<Tip>
  Quetzal es actualmente gratuito para traducciones a un idioma/localización adicional. Si necesitas soporte para múltiples idiomas o un idioma no listado, por favor [contáctenos](https://getquetzal.com/contact)
</Tip>

## Uso del Panel de Control del Proyecto

El Panel de Control es la forma principal de supervisar tus integraciones de Quetzal.

Allí puedes encontrar y administrar el texto en toda tu aplicación, y ver todo el texto traducido.

### Cadenas de Proyecto

La pestaña [cadenas del proyecto](https://getquetzal.com/dashboard/strings/project/0) lista todo el texto que se ha enviado a Quetzal para traducción.

El texto de la cadena y sus traducciones se pueden ver y editar desde esta página.

Cada cadena también muestra el archivo de tu código fuente donde se encontró (si aplica), junto con la fecha en que se agregó.

### Lingo del Proyecto

La pestaña de lingo del proyecto (https://getquetzal.com/dashboard/lingo/project/0) ofrece una forma de indicar palabras o frases especiales únicas de tu marca que deben traducirse de maneras particulares.

Puedes usar lingo para especificar traducciones personalizadas o evitar que se traduzca una frase en particular.

## Tareas comunes

<AccordionGroup>
  <Accordion title="Encontrando tu Clave de API">
    Tu clave de API se encuentra en tu [página de configuración del proyecto](https://getquetzal.com/panel-de-control/configuracion/proyecto/0). Tu clave de API es importante y se utilizará para la mayoría de las integraciones, y otorga acceso para solicitar y recuperar texto de tu aplicación. La clave es única para tu proyecto y compartida entre todos los usuarios. Asegúrate de mantenerla privada.
  </Accordion>
  <Accordion title="Agregando Usuarios">
    La [pestaña de usuarios](https://getquetzal.com/dashboard/users/project/111) te permite invitar usuarios para acceder y colaborar en tu proyecto de Quetzal.
  </Accordion>
  <Accordion title="Agregar soporte para un idioma">
    Al seleccionar 'Agregar idioma' en el lado izquierdo del Panel de Control, podrás añadir soporte para un nuevo idioma a tu proyecto
  </Accordion>
